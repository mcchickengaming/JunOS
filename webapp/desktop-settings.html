        Automatic saves

        In Jun's folder

        Tip: a folder on another drive (like D:) keeps her safe even if this drive ever fails.

        Updates

        Get the latest updateJun checks GitHub for new changes, saves herself, updates and restarts. If anything goes wrong she tells you and stays as she is.

        Good to know

        Her memories are locked with your password. Going back to an old save brings back the password you had then.

        The game art and her brain (the model files) aren't in a save, they come back from your game copy and the download. Her setup file (.env) is kept in a save only for reference: going back never changes it, so she always starts the way she's set up now.
